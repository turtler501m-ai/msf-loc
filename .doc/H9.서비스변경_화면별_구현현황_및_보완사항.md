#### [C] `isSettingButtonDisabled` 수정

기존 이용중 서비스에서 설정 가능 범위 확장 필요.

```javascript
const EXISTING_SERVICE_SETTABLE = new Set(['illegalTm', 'blockNumber100', 'infoProviderBlock'])

const isSettingButtonDisabled = (svc) => {
  const modalType = getSettingModalType(svc)
  if (!modalType || modalType === 'autoDefault') return true
  if (isExistingService(svc)) return !EXISTING_SERVICE_SETTABLE.has(modalType)
  return false
}
```
